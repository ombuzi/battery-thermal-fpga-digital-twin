# FPGA-Accelerated Battery Thermal Digital Twin for Real-Time Safety Prediction

## Project Overview

This repository documents the development of an end-to-end model-based hardware engineering project focused on real-time battery thermal prediction and safety control. The project investigates how a physics-based battery thermal model can be developed, simulated, converted into a surrogate machine learning model, optimized for low-latency inference, and eventually deployed on FPGA hardware as part of a physical embedded controller.

The long-term objective is to create a credible engineering pipeline that connects physical system understanding, mathematical modeling, simulation, dataset generation, machine learning, FPGA acceleration, and embedded electronics design. The final system concept is a battery thermal prediction controller capable of receiving sensor inputs from a battery system and producing real-time estimates of temperature rise, thermal risk, and cooling demand.

This repository is structured as a technical portfolio project. Each development stage is documented clearly so that the engineering reasoning, assumptions, equations, code, results, and design decisions can be reviewed and extended.

## Engineering Problem

Battery systems generate heat during charging and discharging. In high-power applications such as electric vehicles, hybrid vehicles, drones, robotics, industrial storage systems, and defense power systems, thermal behavior is critical to safety, reliability, and performance.

A simple temperature sensor can show the present measured temperature, but it does not directly reveal the internal heat distribution or future temperature evolution. The engineering challenge is to predict whether the battery will remain within safe operating limits or move toward a dangerous thermal condition.

The project begins with a simple mathematical model because the fundamental heat balance must be understood before moving to high-fidelity multiphysics simulation, surrogate modeling, and FPGA deployment.

## Current Stage

The current stage is Stage 1: MATLAB Baseline Thermal Model.

This stage creates a first-principles thermal model using a lumped heat-balance equation. The battery is represented as a single thermal body with one average temperature. The model calculates heat generated by electrical current, heat removed by cooling, and the resulting temperature change over time.

The purpose of Stage 1 is to establish a reliable baseline before moving to more advanced simulation and hardware implementation.

## Technical Basis

The first-stage model is based on conservation of energy. The battery generates heat due to internal electrical losses, and heat is removed through cooling to the surrounding environment. The core equation is:

```text
mCp dT/dt = I^2R - hA(T - Tamb)
```

This equation states that the rate of thermal energy stored in the battery equals the heat generated inside the battery minus the heat removed by cooling.
